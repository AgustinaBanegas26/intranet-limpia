# Conclusión

La intranet reúne en una aplicación común procesos que suelen resolverse por canales separados: solicitudes de viáticos y adelantos, rendiciones, ausencias, vacaciones, reservas y comunicaciones internas. La integración de perfiles, novedades, eventos y documentos institucionales también facilita que las distintas sucursales accedan a información compartida desde un mismo punto.

El proyecto aporta trazabilidad mediante estados, responsables y registros asociados a las solicitudes, además de una base técnica con frontend web, API y persistencia relacional. Para consolidar ese aporte en una operación institucional confiable será necesario validar los circuitos con sus responsables, completar la configuración productiva y abordar los límites técnicos consignados en la documentación, en especial almacenamiento, permisos diferenciados y cobertura de pruebas.
